## Featured work

### Restaurant OS

An independent full-stack restaurant operations application covering point of sale, kitchen operations, inventory, procurement and reporting.

I paid particular attention to workflow integrity. The [case study](projects/restaurant-os/CASE_STUDY.md) explains how stock transfers use state transitions, row locking and transaction boundaries, with tests for duplicate dispatches, invalid receipts and company-level access control.

**Technology:** Python, FastAPI, SQLAlchemy, PostgreSQL, React, TypeScript, Alembic, Pytest, Vitest and GitHub Actions.
